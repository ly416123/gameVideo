# 《小马过河：河岸突围》历史样片归档

此目录记录项目早期样片、原创小游戏、实机录屏和旧版剪辑的制作过程。相关视频和游戏资源仅用于回顾或风格参考，不能作为新故事视频的生产输入。

## 新故事生产约束

- 必须由创作者提供完整、深入的故事正文；只提供标题或梗概时不进入生成流程。
- 新视频的画面只使用与故事匹配的角色图和场景图。
- 使用 Remotion 制作镜头运动、字幕及时间线，使用 FFmpeg 封装视频。
- 不录制、不读取、不拼接游戏实机素材；不使用视频生成模型。

新项目请按根目录的 [故事输入模板](../../story-input-template.md) 和 [生产说明](../../../README.md) 创建。这里保留的 `episode-manifest.json`、旧时间线、旧成片、游戏项目和 `gameplay-captures/` 都是历史资料，不属于新流程。
