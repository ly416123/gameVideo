# 《小马过河：河岸突围》

项目方向已改为浏览器 PC 的横版街机清关小游戏。首版制作一关，角色采用成人比例的拟人形态。剧情与首关需求见 [游戏需求草案.md](游戏需求草案.md)。

## 运行游戏

在项目目录执行 `npm run game`，然后在浏览器打开 `http://localhost:4173/`。开场是九张可翻页或跳过的街机像素风静态图；随后进入魔王城下的旧街关，击败街头守卫和投手后，会播放松鼠登场的对话 CG；击败松鼠后，播放解释咒印和妈妈去向的对话 CG，再结算通关。序章结束后播放循环战斗音乐，角色发言时播放马叫或松鼠叫。页面右上角的“声音设置”可分别调整背景音乐、打击音效与角色叫声；音量会保存在本机浏览器中。

操作：WASD 或方向键移动，J 攻击，K 跳跃攻击，L 冲刺，靠近普通敌兵按 U 抓取、再按 U 投掷，I 拾取，Esc 暂停；对话 CG 用 Enter、空格或按钮继续。用 J 或冲刺打碎油桶、石头可取得补给；鸡腿恢复 28 点、汉堡恢复 45 点体力。木棍与铁锤可拾取，装备后增强 J 攻击，使用次数会耗尽。

旧视频工程位于 `src/`，旧视频素材与成片位于 `public/` 和 `out/`，只作参考。游戏代码位于 `game/`，原创故事与四位主角素材仍在 `public/assets/`，游戏中的街景、普通敌兵、道具与可破坏物采用免费网络素材，来源和授权见 `public/assets/free/SOURCES.md`。旧视频策划和约束文档已移除。
