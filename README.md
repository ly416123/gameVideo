# 故事魔改视频生产力工具

本项目用于制作具有抽象视听表达的自媒体故事视频，题材可以来自历史故事、成语故事、神话故事、童话故事和寓言等。视频可以调整叙述节奏、镜头和画面风格，剧情必须忠实于输入故事或确认的原故事。

当前“小马过河”及其游戏、CG、实机录屏是项目早期样片和历史素材，不属于新故事视频的制作依赖。新流程只使用故事内容、静态角色图/场景图、配音和音乐，由 Remotion 与 FFmpeg 生成视频；不采集或插入游戏实机素材，也不依赖视频生成模型。可以做抽象的画面表达，但不能原创剧情、加入现代笑点或增加原故事没有的角色。

项目目标、约束和整体生产方向见 [项目定位与内容生产方案](项目定位与内容生产方案.md)。自动整理素材、按分镜组装成片、人工审核与项目目录规范见 [人工审核与自动组片工作流及目录规范](人工审核与自动组片工作流及目录规范.md)。小马过河游戏剧情与玩法需求见 [游戏需求草案.md](游戏需求草案.md)。

## 内容生产流程

1. 确认故事名称及所依据的故事版本/来源；可提供梗概或正文作为依据。
2. 按原故事整理场景和叙述。可以调整呈现顺序、镜头和节奏，不添加原故事没有的事件、现代笑点或新角色。
3. 为角色和每个场景准备静态图片，可使用 Codex imagegen；本地 Qwen3-TTS 生成旁白。
4. Remotion 用场景图、透明角色图、字幕、旁白、音乐和镜头动效生成视频，FFmpeg 完成封装与交付；审核后归档故事、图片、音频、时间线和成片。

若名称对应多个版本，或来源不足以确认关键情节，应先核对版本或向创作者确认，不自行补造剧情。

## 运行游戏

在项目目录执行 `npm run game`，然后在浏览器打开 `http://localhost:4173/`。开场是九张可翻页或跳过的街机像素风静态图；随后进入魔王城下的旧街关，击败街头守卫和投手后，会播放松鼠登场的对话 CG；击败松鼠后，播放解释咒印和妈妈去向的对话 CG，再结算通关。序章结束后播放循环战斗音乐，角色发言时播放马叫或松鼠叫。页面右上角的“声音设置”可分别调整背景音乐、打击音效与角色叫声；音量会保存在本机浏览器中。

操作：WASD 或方向键移动，J 攻击，K 跳跃攻击，L 冲刺，靠近普通敌兵按 U 抓取、再按 U 投掷，I 拾取，Esc 暂停；对话 CG 用 Enter、空格或按钮继续。用 J 或冲刺打碎油桶、石头可取得补给；鸡腿恢复 28 点、汉堡恢复 45 点体力。木棍与铁锤可拾取，装备后增强 J 攻击，使用次数会耗尽。

游戏代码位于 `game/`，Remotion 视频代码位于 `src/`，游戏与视频素材位于 `public/`，导出成片位于 `out/`。原创故事与角色素材和第三方免费素材分开管理；第三方素材来源见 `public/assets/free/SOURCES.md`。

## 故事抽奖视频

`src/story-lottery-config.ts` 配置候选故事、中奖故事和滚动顺序种子。默认抽中“小马过河”。运行 `npm run start` 可在 Remotion Studio 预览；运行 `npm run render:lottery` 可导出当前 1920×1080 抽奖片段。抽奖滚动配有逐渐放慢的原创音效和 Qwen3-TTS Serena 配音。配音使用迁移到 `/data/code/tools/data/models/huggingface` 的本地权重和 RTX 3060；生成命令见 `scripts/generate_lottery_voice.py`。完整故事视频的时间线和多个故事项目模板是后续生产工具建设方向。

## 输入故事生成审核视频

本地流程接收梗概或故事正文，并在输入中说明来源/版本：

```bash
npm run story:prepare -- --title "三只小猪" --input /path/to/story-source.md
npm run story:create -- --story-id three-little-pigs
```

`story:prepare` 按输入故事整理场景，不强制四幕、固定场次或角色表格式。故事来源、事件、因果与角色须保持忠实；禁止原创剧情、现代笑点和新角色。美术齐全后运行 `story:create`：本地 Qwen3-TTS 使用成熟、沉稳、有智慧感的讲述者声线配音；Remotion 仅使用角色图和场景图制作镜头动效；FFmpeg 封装成 1080p 审核视频。视频目标 3–5 分钟，不得为凑时长扩写剧情。新流程不采集或使用实机游戏录屏，也不使用视频生成模型。可参考[故事输入模板](content/story-input-template.md)。
